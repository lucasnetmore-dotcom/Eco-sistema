# Ecosystem OS — Architecture

## Role
Ecosystem OS is the central control plane. It does not replace the products; it gives the owner one place to see and open them.

## Current product registry
- Finance Flow AI — active — https://financialtp.vercel.app
- Agenda Flow — planned
- Marketing Flow — planned
- AI Flow — planned

## Future shared layers
1. Identity / SSO
2. Organizations and permissions
3. Product registry
4. Billing
5. Notifications
6. Event bus
7. Audit logs
8. Analytics
9. Integrations / API

## Principle
Each product remains independently deployable and owns its domain. Ecosystem OS becomes the root layer as the product family grows.
