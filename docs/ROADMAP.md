# Ecosystem Product Roadmap

## Phase 0 — Foundation
- Ecosystem OS dashboard
- Product registry
- Shared architecture
- Environment separation
- Organization/identity contract
- Event contract
- Audit contract

## Phase 1 — Communication Flow core
- Email provider integration
- Unified inbox
- Contacts/consent
- Templates
- Transactional messages
- Delivery tracking
- Queue/retry/idempotency
- Campaigns
- Suppression/unsubscribe

## Phase 2 — AI Flow read-only intelligence
- AI chat
- Finance/CRM/Agenda read tools
- Executive briefing
- Insights
- Goals
- Usage metering
- Approval center

## Phase 3 — Communication + AI
- AI inbox classification
- Reply drafts
- Reactivation campaigns
- Segmentation suggestions
- AI campaign copy
- Communication execution tools

## Phase 4 — Automation
- Event triggers
- Conditions
- Delays
- Sequences
- AI decision steps
- Human approval steps
- Retry/failure handling

## Phase 5 — Omnichannel
- Official WhatsApp provider
- SMS
- Media/attachments
- Inbound webhook processing
- Channel-specific templates
- Provider health dashboard

## Phase 6 — Business Copilot
- Cross-product reasoning
- Forecasts
- Scenario planning
- Goal execution
- Proactive alerts
- Autonomous low-risk workflows

## Phase 7 — Commercial expansion
- Plans and add-ons
- AI credits
- Message credits
- Usage billing
- Agency/multi-business support
- White-label capability
- API for external developers

## Golden rule
Do not build AI autonomy before permissions, audit, idempotency, cost controls and approval policies are production-grade.
